# Установка скачанным скриптом

Этот дополнительный способ устанавливает Mac USB Studio 2.1.0 (30) в папку **«Программы» вашего пользователя** (`~/Applications`). Общая папка `/Applications`, USB и настройки безопасности не изменяются.

## Двойной щелчок — без ввода команды

1. **[Скачайте Install-Mac-USB-Studio-2.1.0.command.zip](https://github.com/Atlantik56/MacUSBStudio/releases/download/v2.1.0/Install-Mac-USB-Studio-2.1.0.command.zip)** браузером.
2. Откройте ZIP в Finder. После распаковки появится **один файл** `Install-Mac-USB-Studio-2.1.0.command`. ZIP сохраняет право исполнения, которое теряется при обычном скачивании отдельного SH.
3. Дождитесь завершения записи USB и закройте Mac USB Studio, если он открыт. Дважды нажмите файл `.command`. Он предназначен для открытия в Terminal и сразу начинает установку. Вводить `/bin/bash`, `chmod` или букву `д` не нужно.
4. Дождитесь сообщения об установке и открытия приложения. Terminal можно закрыть после завершения.

**Первый запуск может потребовать разрешения macOS.** Исполняемый файл и снятие блокировки Gatekeeper — разные вещи. Если macOS блокирует скачанный `.command`, разрешите именно этот файл через «Системные настройки» → «Конфиденциальность и безопасность» → «Все равно открыть», если такая кнопка доступна. На управляемом Mac это может ограничиваться политикой организации. Если разрешение недоступно, используйте описанный ниже SH или [обычную установку DMG](INSTALLATION.md). Скрипт не снимает карантин. Apple описывает отдельно [блокировку инструментов, открываемых из Finder](https://developer.apple.com/forums/thread/706379).

ZIP содержит самодостаточный скрипт с теми же проверками, что и SH. Приложение скачивается из фиксированного релиза после запуска. Сам ZIP не содержит приложение или установщик macOS.

## Отдельный SH — запуск через /bin/bash

1. **[Скачайте Install-Mac-USB-Studio-2.1.0.sh](https://github.com/Atlantik56/MacUSBStudio/releases/download/v2.1.0/Install-Mac-USB-Studio-2.1.0.sh)** через браузер. Дождитесь окончания загрузки. Если Mac USB Studio уже открыт, дождитесь завершения записи и закройте его.
2. Откройте **Terminal** через Spotlight: нажмите Command–пробел, введите `Terminal` и нажмите Enter.
3. Напечатайте `/bin/bash` и **пробел**. Перетащите скачанный файл из Finder в окно Terminal — путь подставится автоматически. Нажмите Enter. Файлу не нужно добавлять право исполнения через `chmod`.
4. Проверьте название приложения и папку установки. В ответ на вопрос `Установить …? [д/Н]` введите **`д`** и нажмите Enter.
5. Дождитесь скачивания, проверки и сообщения об установке. **Mac USB Studio откроется автоматически.** Повторно открыть его можно из `~/Applications` через Finder.

Если файл находится в обычной папке «Загрузки» и имя не изменено, вместо перетаскивания можно использовать:

```bash
/bin/bash "$HOME/Downloads/Install-Mac-USB-Studio-2.1.0.sh"
```

Двойной щелчок по `.sh` может открыть редактор. Браузер не сохраняет право исполнения shell-файла; установка через `/bin/bash` не зависит от этого права и ассоциации Finder. Однократное скачивание скрипта само по себе не запускает установку.

## Что делает скрипт

- Скачивает один фиксированный DMG по HTTPS из официального релиза этого репозитория. Проверка сертификатов включена; код с удалённого сервера не выполняется.
- Сверяет встроенный SHA-256 образа, идентификатор, версию и номер сборки приложения; проверяет ad-hoc подписи GUI и процесса записи для всех архитектур.
- Подключает только скачанный виртуальный образ для чтения, копирует приложение и отключает этот образ.
- Сохраняет прежнюю копию как `Mac USB Studio.previous-… .app` в той же папке. Более новая версия, чужой файл, символическая ссылка, параллельная установка или работающий процесс записи останавливают обновление.
- Не форматирует флешку и не устанавливает macOS. Для установки самого Mac USB Studio не запрашивается `sudo` или пароль администратора.

Исходник: [install.sh](../install.sh). Опубликованный `.sh` — точная копия этого файла. Его контрольная сумма находится в `SHA256SUMS.txt` того же релиза.

## Разрешения macOS

При прямой загрузке через `curl` карантин обычно не добавляется. Это описано [Apple Developer Technical Support](https://developer.apple.com/forums/thread/706442). Скрипт **не снимает карантин** и не отключает Gatekeeper или другие защиты. Если скачанный DMG или приложение помечены карантином, он останавливается и предлагает [обычную установку DMG](INSTALLATION.md).

Отсутствие системных запросов на любом Mac не гарантируется: версия macOS и политика организации могут менять поведение. Developer ID и нотарификации у сборки нет. При создании флешки пароль администратора и доступ к съёмному тому всё равно подтверждаются отдельно.
