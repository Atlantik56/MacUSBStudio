# Mac USB Studio

Нативное приложение для macOS, которое скачивает официальный установщик Apple или использует уже готовый, затем создаёт загрузочную USB-флешку. Выбор источника, прогресс, журнал и ввод пароля находятся в одном окне.

Текущая версия: **2.1.0**, сборка **30**.

## Что реализовано

- **Скачать macOS.** Выбор пяти последних поколений из каталога Apple; для каждого поколения выбирается последнее доступное обновление. Каталог можно обновить вручную. Сохранённый список явно помечается, если свежий каталог недоступен.
- **Использовать готовый установщик.** Поддерживаются полное приложение `Install macOS … .app`, пакет Apple `InstallAssistant.pkg` и DMG, содержащий один подходящий установщик.
- **Пауза и возобновление загрузки.** Сохраняется скачанная часть; показываются скорость и приблизительное оставшееся время. Загрузка идёт по HTTPS с проверкой сертификатов и возобновляется через HTTP Range.
- **Выбор физического USB.** В списке показаны модель, размер и идентификатор диска. Перед стиранием повторно сверяются сведения устройства. Внутренние диски и виртуальные устройства исключаются.
- **Подготовка носителя.** Выбранная флешка форматируется в GUID/HFS+, затем запись выполняет официальный `createinstallmedia` Apple. Пакет `InstallAssistant.pkg` предварительно извлекается системным `installer`.
- **Встроенная консоль.** Вывод команд и защищённое поле пароля находятся в окне приложения. Для новых записей отдельный Terminal не открывается. Пароль передаётся локальному `sudo` через stdin и не сохраняется в журнале, файлах или аргументах процесса.
- **Этапы и проценты записи.** Ожидание пароля, извлечение пакета, форматирование, копирование и проверка результата отображаются отдельно. 100% стирания не считается завершением всей операции.
- **Восстановление наблюдения.** После получения прав администратора запись выполняется отдельным процессом и продолжается при закрытии интерфейса. При повторном открытии приложение подключается к текущему заданию. Закрытие окна до авторизации отменяет запрос пароля.
- **Проверка результата.** После успешного завершения Apple проверяются GUID/HFS+, признак загрузочного тома, `.IAPhysicalMedia` и полный набор данных установщика. Журнал и результат сохраняются независимо от окна приложения.
- **Безопасное извлечение.** После успешной записи появляется кнопка «Безопасно извлечь флешку». Она извлекает USB из завершённого задания после повторной проверки устройства; принудительное размонтирование не применяется.

Установка самой macOS на внутренний диск при создании флешки **не запускается**. `InstallAssistant.pkg` содержит установщик системы и не является зависимостью Mac USB Studio: если полное приложение установщика уже сохранено, пакет можно удалить.

## Запуск

1. Скачайте [Mac.USB.Studio-2.1.0.pkg](https://github.com/Atlantik56/MacUSBStudio/releases/download/v2.1.0/Mac.USB.Studio-2.1.0.pkg) и откройте двойным щелчком.
2. Пройдите стандартную установку macOS. Приложение появится в «Программы»; установщик попробует открыть его для текущего пользователя. Если окно не появилось, откройте «Программы» → `Mac USB Studio`. Распаковка архива не нужна.
3. Выберите «Скачать macOS» или «Готовый установщик».
4. Подключите USB и выберите нужный накопитель.
5. Нажмите «Создать загрузочную флешку…» и подтвердите стирание указанного USB. **Все данные на выбранной флешке будут удалены.**
6. Если понадобится пароль администратора, введите его в защищённом поле под журналом. Запрос доступа к съёмным томам подтверждается в системном окне macOS.
7. Дождитесь сообщения о готовности. Нажмите «Безопасно извлечь флешку», дождитесь подтверждения и отключите USB.

`Mac.USB.Studio-2.1.0.pkg` устанавливает **только Mac USB Studio** и не содержит macOS. Это другой пакет, чем установщик системы Apple `InstallAssistant.pkg`. Установка приложения сама не запускает запись на USB. ZIP с той же `.app` оставлен в Releases для ручного размещения приложения.

Для выбора флешки при запуске Mac: на Apple Silicon удерживайте кнопку питания до появления вариантов загрузки; на Intel удерживайте Option. Выбранная версия macOS должна поддерживать целевой Mac. [Инструкция Apple](https://support.apple.com/en-us/101578).

## Требования и ограничения

- macOS 13 или новее. Приложение собрано для Apple Silicon и Intel (`arm64` и `x86_64`).
- Физическая USB-флешка от 24 ГБ; рекомендуется 32 ГБ или больше. Для большого установщика потребуется соответствующий объём.
- Права администратора и свободное место для скачивания и подготовки установщика.
- Приложение не меняет настройки VPN, Kill Switch и конфиденциальности macOS. Системные запросы разрешений остаются окнами macOS.
- Проверки SMART/здоровья USB нет.
- Готовая `.app` подписана локальной **ad-hoc** подписью, установочный `.pkg` не подписан. Developer ID и нотарификация Apple пока не настроены. При открытии скачанного установщика или приложения macOS может потребовать явного разрешения пользователя.
- Проверка структуры носителя не заменяет фактическую загрузку на целевом Mac.

## Проверено в версии 2.1.0

Пройдены **70 автоматических проверок** без записи на USB. Проверены выбор поколений, доверенные адреса, этапы и проценты, сравнение устройства, наблюдение за процессами, передача пароля, отмена авторизации и условия безопасного извлечения.

Полный реальный цикл записи **macOS Sequoia** на USB 62,91 ГБ выполнен через встроенную консоль: авторизация, форматирование, запись, завершение с кодом 0 и проверка содержимого. В окне подтверждены прогресс и кнопка безопасного извлечения. Аппаратная загрузка с этого носителя на целевом Mac не проверялась. Подробнее — [VALIDATION.md](VALIDATION.md).

## Сборка из исходников

Нужны macOS и Xcode Command Line Tools с компилятором Swift.

```bash
git clone https://github.com/Atlantik56/MacUSBStudio.git
cd MacUSBStudio
bash build.sh
open "build/Mac USB Studio.app"
```

Скрипт собирает универсальные GUI и отдельный процесс записи, подписывает их ad-hoc, проверяет подписи и запускает 70 проверок. Для отдельной проверки паузы и возобновления загрузки на localhost:

```bash
python3 Tests/Resume.py "build/Mac USB Studio.app/Contents/MacOS/MacUSBStudio"
```

Для создания установочного `.pkg` нужны системные `pkgbuild`, `productbuild` и Python 3:

```bash
bash package.sh
```

Результат: `dist/Mac.USB.Studio-2.1.0.pkg`. Скрипт использует готовую сборку из `build/` или сначала вызывает `build.sh`, если её нет; сверяет идентификатор, версию и подписи. Можно передать путь к другой собранной `.app` первым аргументом. Приложение устанавливается строго в `/Applications` и не перемещает копию на рабочем столе. После установки GUI открывается с правами текущего пользователя; повышенные права остаются только у системного установщика. Установка и автоматический запуск на отдельном Mac пока не проверены.

## Исходники и данные

| Файл | Назначение |
| --- | --- |
| `Sources/App.swift` | Интерфейс AppKit, выбор источника, загрузка и управление заданием |
| `Sources/Catalog.swift` | Каталог Apple, выбор поколений и параметры загрузки |
| `Sources/Console.swift` | Встроенная консоль и передача пароля через stdin |
| `Sources/Recorder.swift` | Процесс записи с правами администратора |
| `Sources/Domain.swift` | Модель USB, сравнение устройства и этапы записи |
| `Sources/Monitoring.swift` | Наблюдение за процессами, журналом и результатом |
| `Sources/Ejection.swift` | Проверка и безопасное извлечение записанного USB |
| `Sources/System.swift` | Системные утилиты, подписи и проверки установщика |
| `Tests/` | Автоматические и интеграционные проверки |
| `package.sh`, `Packaging/` | Сборка установочного PKG, страницы установщика и запуск приложения после установки |

Скачанные установщики хранятся в `~/Library/Application Support/Mac USB Studio/downloads`, состояние интерфейса — в `clean-v2` внутри той же папки. Журналы и подготовленные задания находятся в `/private/tmp/mac-usb-studio2-…`.

В репозитории находятся исходники, тесты и документация. Готовое приложение публикуется в Releases; пакеты и образы macOS в репозиторий не включаются.
