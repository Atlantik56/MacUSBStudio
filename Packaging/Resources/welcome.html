Mac USB Studio

Создание загрузочной флешки macOS из готового установщика или с загрузкой одного из пяти последних поколений системы.

Установщик поместит приложение в «Программы». Распаковывать архив и выбирать исполняемый файл не нужно.

Для установки приложения macOS может запросить пароль администратора в системном окне. Создание флешки запускается отдельно, по вашей команде в приложении.
