Mac USB Studio установлен

Приложение находится в «Программы» → Mac USB Studio.

Установщик пробует открыть приложение для текущего пользователя. Если окно не появилось, откройте Mac USB Studio из «Программ».

Сборка пока не нотарифицирована Apple: при первом запуске может потребоваться разрешение macOS.

Выберите источник macOS, затем нужную флешку. Данные выбранного USB будут удалены только после вашего подтверждения в приложении.
