# Проверки версии 2.1.0

Дата: 2 октября 2026, Москва. Версия приложения 2.1.0, сборка 30.

## Сборка

- GUI и отдельный `MacUSBRecorder` собраны для `arm64` и `x86_64` с минимальной версией macOS 13.
- Локальные ad-hoc подписи обоих компонентов проверены `codesign --verify --strict`.
- **70 автоматических проверок пройдены.** Они не форматируют накопители и не записывают данные на USB.

## Автоматические проверки

- Последнее доступное обновление для каждого из пяти поколений; числовое сравнение версий.
- Проверка доверенных HTTPS-адресов Apple и сохранение проверки TLS.
- Синтаксис команд, экранирование путей и восстановление загрузки с точного смещения.
- Разделение стирания, копирования, подготовки загрузки и финальной проверки.
- Исключение внутреннего, изменившегося или неоднозначного USB.
- Наблюдение за процессами с русскими именами команд; `/tmp` и `/private/tmp`.
- Работающий процесс, устаревший PID, ошибка чтения процессов и неполная UTF-8 строка в журнале.
- Распознавание запросов и повторных запросов пароля; запрет многострочного ввода; отсутствие пароля в журнале и аргументах.
- Сохранение вывода после закрытия stdin; отмена до получения прав администратора.
- Запрет извлечения при неуспешной/незавершённой записи, работающем процессе или изменившемся устройстве.

Отдельный тест `Tests/Resume.py` использует настоящий curl и локальный HTTP-сервер. При паузе сохраняется префикс, затем проверяются точный Range и побайтовое совпадение полного файла. Он не обращается к Apple и не меняет USB. Тест повторно пройден на сборке из публикуемого репозитория.

## Проверка встроенной консоли на реальном USB

На USB VendorC ProductCode Media, 62 914 560 000 байт, выполнен отдельный тест прав администратора и доступа к тому. Пользователь ввёл пароль в защищённом поле приложения. Процесс с правами администратора создал, прочитал и удалил один временный файл. Результат успешный, код 0; форматирование и установщик в этом тесте не запускались.

## Полный цикл записи Sequoia

Из приложения `Install macOS Sequoia.app` выполнена запись на тот же физический USB через встроенную консоль версии 2.1.0.

Подтверждены:

- Ввод пароля внутри приложения и получение прав администратора.
- Форматирование GUID/HFS+ и запуск официального `createinstallmedia`.
- Отображение этапов и процентов копирования в настоящем окне AppKit.
- Завершение с кодом 0 и успешный результат задания.
- Повторное совпадение модели, реестра устройства, порта, размера и идентификатора USB.
- Том `Install macOS Sequoia`, GUID/HFS+, `Bootable=true`, `.IAPhysicalMedia` и полный `SharedSupport.dmg` размером 15 664 523 626 байт.
- Появление активной кнопки безопасного извлечения. Команда извлечения проверена без её выполнения; выбран именно USB из завершённого задания.
- Сохранение завершённого задания и удаление указателя активной записи.

Саму ОС на внутренний диск не устанавливали. Аппаратная загрузка на целевом Mac не проверялась. Сборка Intel подготовлена, но полный цикл на отдельном Intel Mac не выполнялся. Поддержка других установщиков реализована; эта проверка полного цикла относится к Sequoia.

## Установка через Terminal

- Реальное скачивание ZIP релиза с GitHub проверено; встроенный SHA-256 совпал, идентификатор, версия 2.1.0 (30) и подписи GUI/процесса записи подтверждены.
- Пройдены **9 интеграционных проверок** `Tests/Install.py` на macOS 26.5.1. Все операции выполнялись в частных временных папках; окно приложения не запускалось.
- Новая установленная копия побайтово совпала с релизом, подпись сохранилась, карантин отсутствует у всех её файлов. Карантин исходного ZIP, предыдущей копии и посторонней папки остался неизменным.
- Неверный SHA-256 не изменяет установленную копию. Чужая программа, символическая ссылка, более новая версия/сборка и занятая блокировка установки сохранены.
- Рабочий временный процесс с именем MacUSBRecorder блокирует установку до создания папки назначения. Он не форматирует накопители и не обращается к USB.
- Прежняя версия при обновлении сохраняется рядом. Установка не меняет глобальный Gatekeeper, VPN или разрешения macOS.
- Скрипт снимает карантин этой копии; это не Developer ID и не нотарификация. Первое открытие на отдельном чистом Mac ещё не проверено.

## Запуск установочного скрипта из Finder

- В релиз добавлены `install-mac-usb-studio.command` и ZIP с этим единственным файлом. Содержимое побайтово совпадает с `install.sh`; логика установки приложения не изменена.
- ZIP распакован системным `ditto`: право исполнения `755` сохраняется. Синтаксис Bash и вывод `--help` проверены без установки приложения.
- На текущем Mac скачанный установщик переименован из `.sh` в `.command`, ему установлено право исполнения. Через системный NSWorkspace назначен Terminal только этому файлу; чтение ассоциации подтверждает `/System/Applications/Utilities/Terminal.app`.
- Установка из Finder и первое открытие скрипта на отдельном Mac в этой проверке не выполнялись. Скачанный скрипт может требовать разрешения Gatekeeper; браузерная загрузка отдельного `.command` может потерять право исполнения, поэтому для двойного щелчка предлагается ZIP.
