# Проверки версии 2.1.0

Дата: 2 октября 2026, Москва. Версия приложения 2.1.0, сборка 30.

## Сборка

- GUI и отдельный `MacUSBRecorder` собраны для `arm64` и `x86_64` с минимальной версией macOS 13.
- Локальные ad-hoc подписи обоих компонентов проверены `codesign --verify --strict`.
- **70 автоматических проверок пройдены.** Они не форматируют накопители и не записывают данные на USB.

## Автоматические проверки

- Последнее доступное обновление для каждого из пяти поколений; числовое сравнение версий.
- Проверка доверенных HTTPS-адресов Apple и сохранение проверки TLS.
- Синтаксис команд, экранирование путей и восстановление загрузки с точного смещения.
- Разделение стирания, копирования, подготовки загрузки и финальной проверки.
- Исключение внутреннего, изменившегося или неоднозначного USB.
- Наблюдение за процессами с русскими именами команд; `/tmp` и `/private/tmp`.
- Работающий процесс, устаревший PID, ошибка чтения процессов и неполная UTF-8 строка в журнале.
- Распознавание запросов и повторных запросов пароля; запрет многострочного ввода; отсутствие пароля в журнале и аргументах.
- Сохранение вывода после закрытия stdin; отмена до получения прав администратора.
- Запрет извлечения при неуспешной/незавершённой записи, работающем процессе или изменившемся устройстве.

Отдельный тест `Tests/Resume.py` использует настоящий curl и локальный HTTP-сервер. При паузе сохраняется префикс, затем проверяются точный Range и побайтовое совпадение полного файла. Он не обращается к Apple и не меняет USB. Тест повторно пройден на сборке из публикуемого репозитория.

## Проверка встроенной консоли на реальном USB

На USB VendorC ProductCode Media, 62 914 560 000 байт, выполнен отдельный тест прав администратора и доступа к тому. Пользователь ввёл пароль в защищённом поле приложения. Процесс с правами администратора создал, прочитал и удалил один временный файл. Результат успешный, код 0; форматирование и установщик в этом тесте не запускались.

## Полный цикл записи Sequoia

Из приложения `Install macOS Sequoia.app` выполнена запись на тот же физический USB через встроенную консоль версии 2.1.0.

Подтверждены:

- Ввод пароля внутри приложения и получение прав администратора.
- Форматирование GUID/HFS+ и запуск официального `createinstallmedia`.
- Отображение этапов и процентов копирования в настоящем окне AppKit.
- Завершение с кодом 0 и успешный результат задания.
- Повторное совпадение модели, реестра устройства, порта, размера и идентификатора USB.
- Том `Install macOS Sequoia`, GUID/HFS+, `Bootable=true`, `.IAPhysicalMedia` и полный `SharedSupport.dmg` размером 15 664 523 626 байт.
- Появление активной кнопки безопасного извлечения. Команда извлечения проверена без её выполнения; выбран именно USB из завершённого задания.
- Сохранение завершённого задания и удаление указателя активной записи.

Саму ОС на внутренний диск не устанавливали. Аппаратная загрузка на целевом Mac не проверялась. Сборка Intel подготовлена, но полный цикл на отдельном Intel Mac не выполнялся. Поддержка других установщиков реализована; эта проверка полного цикла относится к Sequoia.

## Распространение в DMG

- `dmg.sh` подготовил `Mac.USB.Studio-2.1.0.dmg` с приложением и ярлыком `/Applications`.
- `Tests/DMG.py` подтвердил контрольную сумму образа, полный набор файлов и побайтовое совпадение приложения с проверенной сборкой, ad-hoc подписи GUI и `MacUSBRecorder`, архитектуры `arm64` и `x86_64`.
- Для проверки подключался только DMG для чтения; затем отключён только этот виртуальный образ. Физические USB не использовались.
- Выполнены браузерная загрузка DMG и копирование через Finder в `/Applications`. SHA-256 браузерной копии совпал; карантин на образе и скопированном приложении сохранился. Атрибуты не снимались; упаковка и копирование не меняли настройки безопасности.
- При открытии скопированного приложения Gatekeeper заблокировал запуск. В «Конфиденциальность и безопасность» проверено сообщение именно о Mac USB Studio и кнопка «Все равно открыть». Пользователь разрешил запуск в macOS; затем подтверждено настоящее окно приложения из `/Applications`. На отдельном чистом Mac и на Intel этот путь ещё не проверялся.
- DMG не подписан Developer ID и не нотарифицирован. Инструкция описывает явное разрешение первого запуска в настройках macOS. Скриншоты окна DMG сняты при этой проверке; примеры предупреждения и настроек безопасности приведены из документации Apple с указанием источника.

## Самостоятельный SH-установщик

- `Tests/ScriptInstaller.py`: **12 интеграционных проверок пройдены** в отдельных папках `/private/tmp`. Проверены побайтовое совпадение с проверенной сборкой, русские имена и пробелы в пути, сохранение прежней копии, отказ при чужом файле, символических ссылках, блокировке установки, более новой версии, неверном SHA-256 и работающем процессе записи. Проверены режим без установки, очистка своих временных папок/подключений и явное подтверждение для автоматического запуска.
- Тестовый DMG с карантином отклонён; значение `com.apple.quarantine` осталось тем же. Скрипт не удаляет этот атрибут и не меняет настройки безопасности.
- Опубликованный SH скачан через обычный Yandex Browser. Его SHA-256 совпал с исходником; браузер сохранил режим `0644` и атрибут карантина. Файл успешно выполнен через `/bin/bash` без `chmod` в отдельную временную папку: настоящий релиз скачан по HTTPS, SHA-256 и подписи проверены, все файлы установленного приложения совпали с проверенной сборкой. Карантин самого SH сохранился, у загруженного этим запуском приложения карантин не обнаружен.
- Доступ инструмента «Компьютер» к системному Terminal запрещён. Поэтому эта проверка выполнена в командной сессии; запуск кликом в системном Terminal не заявляется. Первый запуск на отдельном чистом Mac и поведение корпоративных политик не проверены. Отсутствие системных запросов на любом Mac не гарантируется.
- Затем по просьбе пользователя скачанный SH выполнен интерактивно через `/bin/bash` с подтверждением `д`. Установка в `~/Applications` завершилась с кодом 0, прежняя копия сохранена, настоящее окно установленного Mac USB Studio проверено. Пароль администратора не запрашивался.
- Физические USB при проверке установщика не использовались. Версия и исполняемые файлы самого Mac USB Studio не изменены.

## Исполняемый скрипт в ZIP

- `command-zip.py` создаёт ZIP с одним самостоятельным `.command`, режимом Unix `0755` и встроенным полным содержимым `install.sh`. Аргумент `--yes` добавляется автоматически; проверки релиза и защиты замены приложения сохраняются.
- `Tests/CommandZIP.py` проверяет ровно один файл в архиве, режим `0755` в ZIP и после распаковки через `ditto`, точное совпадение кода с исходником, синтаксис и прямое выполнение файла без ввода `/bin/bash` или `chmod`. Реальный DMG проверен в режиме `--verify-only`; приложение не устанавливается. Дополнительно проверено отсутствие запроса текстового подтверждения при сохранении отказа на ошибке.
- Этот тест проверяет исполнение и упаковку. Двойной щелчок в Finder с переходом в системный Terminal и поведение Gatekeeper на чистом Mac не проверены: доступ инструмента к Terminal запрещён. В инструкции явно указано возможное разрешение первого запуска.
